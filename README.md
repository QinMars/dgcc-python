# dgcc-python
A Python reproduction of DGCC (Differential Grouping-based Cooperative Coevolution) for large-scale global optimization, featuring DG-based variable decomposition, SaNSDE subcomponent optimizers, and experimental evaluation on the CEC 2010 benchmark suite.
Implement a Python reproduction of DGCC (Differential Grouping-based Cooperative Coevolution) for Large-Scale Global Optimization (LSGO), covering variable interaction detection, problem decomposition, subcomponent optimization, cooperative coevolution, and experimental benchmarking.

**1. Differential Grouping (DG)**

- Implemented the Differential Grouping algorithm as a preprocessing stage before the main optimization process.
- Allocated a portion of the total function evaluation (FE) budget to detect interactions and dependencies among decision variables.
- Decomposed the original high-dimensional optimization problem into subcomponents according to the detected variable interactions.

**2. SaNSDE Subcomponent Optimizer**

- Reimplemented the core optimization logic of Self-adaptive Differential Evolution with Neighborhood Search (SaNSDE).
- Integrated SaNSDE as the underlying optimizer for individual subcomponents.
- Adopted independently selected parameter settings where the original paper did not provide sufficient implementation details. Consequently, some parameter configurations may differ slightly from those used in the original experiments.

**3. Cooperative Coevolution (CC) Framework**

- Designed and implemented a cooperative coevolution framework to coordinate multiple subcomponent optimizers.
- Dynamically instantiated subcomponent optimizers according to the decomposition results generated by Differential Grouping.
- Restricted each subcomponent optimizer to manipulating only its assigned subset of decision variables.
- Implemented tailored fitness functions for individual subcomponent optimizers using a context-vector-based evaluation mechanism.
- Embedded each candidate subcomponent solution into the current global best solution vector while keeping all non-assigned dimensions fixed, enabling fitness evaluation in the original high-dimensional search space.

**4. Experimental Logging and Visualization**

- Implemented text-based logging to record the optimization process and experimental results.
- Integrated Matplotlib for basic graphical visualization and tabular presentation of experimental results.
- Provided a lightweight experimental environment for monitoring and analyzing algorithm performance.

**5. Benchmark Integration and Experimental Results**

- Integrated the CEC 2010 Large-Scale Global Optimization benchmark suite through the opfunu Python library.
- Evaluated the reproduced DGCC algorithm on the benchmark functions and compared the obtained results with those reported in the original publication.
- Preliminary experimental results are generally comparable to the reported results, with approximately one order of magnitude lower objective values on certain benchmark functions.
- These discrepancies may be attributable to stochastic variability and differences in the parameter configurations of the SaNSDE subcomponent optimizers.

**6. Reproduction Scope and Limitations**

This project aims to reproduce the fundamental algorithmic mechanisms and experimental behavior of DGCC rather than guarantee an exact numerical replication of the original results.

Further repeated experiments and standardized comparisons are required to determine whether the observed performance differences are statistically significant.
